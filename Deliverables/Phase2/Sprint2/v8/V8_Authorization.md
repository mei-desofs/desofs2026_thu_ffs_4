## Implementation Notes

- Role-based route protection is enforced in `CantinasApp/Backend/src/middlewares/authorizeRoles.ts` and route files.
- Session-aware contextual authorization is enforced in `CantinasApp/Backend/src/middlewares/authMiddleware.ts` and `CantinasApp/Backend/src/Service/SessionService.ts`.
- Ownership and field-level restrictions are implemented for:
  - applications in `CantinasApp/Backend/src/Controller/ApplicationController.ts`
  - reservations in `CantinasApp/Backend/src/Controller/ReservationController.ts`
  - notifications in `CantinasApp/Backend/src/Controller/NotificationController.ts`
- The application now uses current database-backed user roles for authorization decisions rather than only the role embedded in the JWT.
