## 🎓 Key Learnings

1. **Service Layer Validation** - Password checks must be in service, not just controller
2. **Token Security** - CSPRNG + expiry + single-use prevents most token attacks
3. **Audit Everything** - Login attempts should always be logged for forensics
4. **Generic Errors** - Prevent user enumeration by returning same error for all auth failures
5. **Rate Limiting** - Essential for brute force protection (already had, now extended)
